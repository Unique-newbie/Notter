# NotterPad Roadmap

This roadmap outlines the past achievements, current focus, and future direction of NotterPad. We welcome community feedback and contributions at every stage!

## ✅ Completed (v2.0)

- **Offline-First Migration**: Transitioned core architecture to function entirely without an internet connection.
- **IndexedDB Storage Engine**: Robust local data persistence ensuring speed and privacy.
- **Unified Settings**: Implemented a comprehensive 6-tab Settings panel for granular control.
- **Cascading Deletion**: Safe and complete removal of hierarchical data (novels -> chapters -> scenes).
- **BYOK AI Extraction**: Secure "Bring Your Own Key" implementation for AI character/location extraction.

## 🚧 In Progress (v2.1)

- **Enhanced Graph Filters**: Advanced filtering mechanisms for the Knowledge Graph visualization.
- **Offline Export Presets**: Pre-configured templates for exporting novel manuscripts locally.

## 📅 Planned (v2.2)

- **Advanced Export Options**: Native export support for EPUB and fully formatted `.docx` files.
- **Custom Schema Fields**: Allow users to define custom metadata fields for characters, locations, and world-building elements.

## 💡 Future Ideas

- **Local Vector Search**: Implement local vector embeddings (e.g., Transformers.js) for semantic search across story lore.
- **Desktop Wrapper**: Native desktop application builds via Tauri or Electron for deeper OS integration.

## Contribute

See an item on the roadmap you're passionate about? Check out our `CONTRIBUTING.md` and jump into the issue tracker! Look for the `help wanted` or `good first issue` labels.
