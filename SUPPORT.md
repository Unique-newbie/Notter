# Support

Welcome to the NotterPad community! If you need help, have a question, or want to suggest a new feature, we offer several ways to get support.

## 💬 GitHub Discussions

For general questions, sharing ideas, showing off how you use NotterPad, or connecting with other users, please use **[GitHub Discussions](../../discussions)**. This is the best place to ask "How do I...?" or to propose new concepts before creating a formal feature request.

## 🐛 Bug Reports & 🚀 Feature Requests

If you've found a bug or have a clear feature request, please open an issue on our **[GitHub Issues](../../issues)** page. 

- **Bug Reports**: Please use the Bug Report issue template and provide as much detail as possible, including steps to reproduce, your browser version, and OS.
- **Feature Requests**: Please use the Feature Request issue template and clearly describe the problem you're trying to solve and your proposed solution.

## 📖 Documentation

Check out our documentation for guides, FAQs, and API references (links will be updated as the documentation site goes live).

Thank you for being part of the NotterPad community!
