# Changelog

All notable changes to NotterPad will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.2.0] - Current
### Added
- BYOK (Bring Your Own Key) architecture for AI extraction.
- Consolidated 6-tab Settings interface.

### Changed
- Complete transition to Offline-First Engine utilizing IndexedDB.
- Overhauled deletion system with Total Cascading Purge for data consistency.

### Fixed
- Comprehensive bug audit resolving edge cases in local state management.

## [2.1.0] - Previous
### Added
- Sprint Mode 2.0 with enhanced tracking and analytics.
- Zen Writing Pad for distraction-free drafting.
- Interactive Knowledge Graph for visualizing story connections.

## [2.0.0] - Previous
### Changed
- Major architectural shift: Offline-First Migration.
- Replaced cloud dependency with IndexedDB Storage Layer.

## [1.0.0] - Initial
### Added
- Initial Prototype & Cloud MVP release.
- Basic text editing and novel organization functionalities.
